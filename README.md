# Smart Alarm Event Simulator

Smart Alarm Event Simulator is a Java console application that emulates a basic security system and common alarm events.

## Features

- Door open simulation
- Fire detection
- Alarm trigger
- Power failure event
- Event history
- Notification simulation
- Configurable system
- Modular architecture

## Project Structure

```
config/
controller/
models/
services/
utils/
resources/
```

## Example Output

```
[Notification] DOOR_OPEN detected
[Notification] FIRE detected
[Notification] POWER_LOSS detected
[Notification] ALARM detected
```
